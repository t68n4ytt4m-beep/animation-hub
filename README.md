# Animation Hub

Animation Hub is a personal, non-commercial Kodi add-on designed
to organise animated television series by their broadcasting networks
and franchises.

## Features

- Network-based animation catalogue
- Disney, Warner Bros., Nickelodeon and anime categories
- TMDb integration for series metadata
- Automatic poster and backdrop artwork
- Network logos and series descriptions
- Custom Kodi interface
- Integration with existing Kodi playback add-ons

## Development

Animation Hub is currently under development for personal home use.

TMDb provides metadata and artwork information.
This project is not affiliated with or endorsed by TMDb or Kodi.

No commercial services, subscriptions or revenue are associated
with this project.
